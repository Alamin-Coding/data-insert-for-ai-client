Question:
বাস্তব সংখ্যায় [math](x – 1 ) ( x + 2 ) > 0[/math] অসমতার সমাধান সেট নির্ণয় কর।

Options:


Correct Answer: 

Solution:

[Image]
[math]\therefore[/math]
 নির্ণের সমাধান [math]x1[/math]


Explanation:
দুই গুণকের শূন্যবিন্দু হল [math]x=1[/math] এবং [math]x=-2[/math]; অসমতাটি ধনাত্মক হলে দুই গুণকই একই চিহ্নে হতে হবে। তাই [math]x1[/math] হলে উভয় পজিটিভ, সুতরাং সমাধান সেট [math](-\infty,-2)\cup(1,\infty)[/math]।

Question:
মান নির্ণয় কর : [math]|3 x-4|<2[/math]

Options:


Correct Answer: 

Solution:
[math]|3 x-4|<2 \Rightarrow-2<3 x-4<2 \Rightarrow-2+4<3 x<2+4 \Rightarrow 2<3 x<6 \Rightarrow \frac{2}{3}

Explanation:
এটি কারণ সাধারণভাবে [math]|A|<b[/math] হলে [math]-b<A<b[/math] হয়; তাই [math]|3x-4|<2[/math] থেকে [math]-2<3x-4<2[/math], 4 যোগ করলে [math]2<3x<6[/math] এবং 3 দিয়ে ভাগ করলে [math]\tfrac{2}{3}<x<2[/math] হয়। ফলে সমাধান হল [math](\tfrac{2}{3},\,2)[/math]।

Correct Answer:

Question:
অসমতা [math]x^{2} \leq x[/math] এর সমাধান কি হবে?

Options:


Correct Answer: 

Solution:
[math]x^{2} \leq x \Rightarrow x^{2}-x \leq 0 \Rightarrow x(x-1) \leq 0 \quad \therefore 0 \leq x \leq 1[/math]

Explanation:
সমীকরণকে একপাশে আনলে পাই [math]x^2 - x \le 0[/math], অর্থাৎ [math]x(x-1)\le 0[/math]. যেহেতু দুটি গুণফলের মান শূন্য বা ভিন্ন চিহ্ন হলে শর্ত পূরণ করে, তাই সমাধান হল [math]x\in[0,1][/math]।

Question:
বাস্তব সংখ্যায় [math](x – 1 ) ( x + 2 ) > 0[/math] অসমতার সমাধান সেট নির্ণয় কর।

Options:


Correct Answer: 

Solution:

[Image]
[math]\therefore[/math]
 নির্ণের সমাধান [math]x1[/math]


Explanation:
শূন্যবিন্দু হল [math]x-1=0\Rightarrow x=1[/math] এবং [math]x+2=0\Rightarrow x=-2[/math]। দুইটি গুণক একই চিহ্নে হলে গুণফল ধনাত্মক হয়, তাই [math]x>1[/math] (উভয় ধনাত্মক) বা [math]x<-2[/math] (উভয় ঋণাত্মক), এবং অসমতা কঠোর হওয়ায় শূন্যবিন্দুসমূহ অন্তর্ভুক্ত হবে না; ফলে সমাধান সেট [math](-\infty,-2)\cup(1,\infty)[/math]।
